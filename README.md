# Flip-7-game
A browser-based Flip 7 card game built using HTML, CSS, and JavaScript.

## Features
- Multiplayer support
- Card animations
- Flip Three cards
- Freeze cards
- Second Chance system
- Score tracking
- Round system

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
1. Download the repository
2. Open `index.html` in a browser
